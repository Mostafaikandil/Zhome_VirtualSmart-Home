# Zhome Experience · Virtual Dubai Villa

An interactive Zhome showroom for exploring how lighting, cooling, audio, and curtains can work together in a Dubai villa living room.

## Run it

Open `index.html` in a browser. Put `index.html` and `README.md` in the repository root. The HTML contains the styles, controls, and all images. It runs offline with no installation, build step, or asset folder.

## Try the experience

Use **Start tour** to follow five spotlighted steps. Click the highlighted area or **Next** to advance. The room controls are paused while the tour is open and resume when you exit. You can also choose Welcome Home, Cinema, Good Night, or Away and explore freely. The display tabs control lighting and white tone, simulated AC, locally generated ambient audio, and curtain position. **Simulate vacancy** applies Away. **Simulate arrival** brings back Welcome Home.

This is a browser simulation. It does not connect to a Loxone Miniserver or home devices. It asks for no permissions, uses no analytics or accounts, and does not send your interactions anywhere. Audio starts only after a user action. Motion follows your browser’s reduced-motion preference.
